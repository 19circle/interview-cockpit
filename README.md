## 这是什么

一套完整的测试开发社招面试冲刺材料，覆盖 **13 天 × 每天 6 小时** 的可执行计划，
约 200 道高频面试题（含完整参考答案、结合本人项目的答法、层层追问链），
以及 STAR 故事集、HR 谈薪话术、投递台账与面试复盘模板。

## 阅读方式

- **在线驾驶舱**：点击上方链接，首页为可交互驾驶舱（倒计时 / 进度环 / 打卡 / 雷达图 / 台账管理）
- **直接读文档**：驾驶舱内点击任一文件卡片即可打开对应页面
- **动态渲染任意 Markdown**：打开 [`viewer.html`](viewer.html)，从下拉框选择文件即时渲染
- **原始 Markdown**：每个页面右上角有「原始 Markdown」入口

## 本地使用

```bash
git clone https://github.com/19circle/interview-cockpit.git
cd interview-cockpit
# 直接双击 index.html 即可离线使用（零 CDN 依赖）
```
