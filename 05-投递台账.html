05 · 投递台账

本文件是尹胜深圳求职的"弹药库 + 仪表盘"。每次投递、每次跟进都请如实登记，13 天集中轰炸期内每天花 5 分钟更新，比海投后焦虑地猜"石沉大海了吗"更有用。

使用说明

  1. 登记节奏：每天投递结束后 5 分钟内登记本日新增投递；出现状态变化（已读 / 约面 / 已面 / 二面 / offer / 挂 / 沉默）随时更新。
  2. 状态机（唯一口径，请用下拉或统一写法）： 待投 → 已投 → 已读 → 约面 → 已面 → 二面 → offer / 挂 / 沉默7天 - 已读：HR/招聘方打开过简历或已读消息。 - 沉默7天：已投/已读后连续 7 天无任何互动，标记为"沉默7天"，批量重投或换渠道。
  3. 看板与记录的关系：看板（第二部分）是手动汇总，由"三、投递记录表"的实时数据每周一、周四手动统计一次。
  4. 优先级标记：在记录表用 P0/P1/P2 标注投递优先级，P0 为第一梯队金融科技乙方，P1 为甲方金融科技，P2 为互联网/软件自动化方向。

一、投递状态看板（手动维护）

每周一、周四从"三、投递记录表"统计一次，复制下表更新数字。转化率 = 下游状态数 / 上游状态数。

状态 数量 较上次 备注
待投 0 — 池内剩余未投
已投 0 — 已发出简历/打招呼
已读 0 — 被查看/已读
约面 0 — 进入面试邀约
已面 0 — 完成一面
二面 0 — 进入二面及以上
offer 0 — 收到录用意向
挂 0 — 明确未通过
沉默7天 0 — 需重投/换渠道
合计（已投） 0 — 总投递量
面试转化率 0% — 约面数 / 已投数
offer转化率 0% — offer数 / 已投数

目标基线（13 天计划参考）：首轮累计投递 130–180 家；约面率目标 ≥ 12%；offer 目标 ≥ 3 个再择优。

二、深圳目标公司池（重点）

四、每日投递节奏表（对齐 13 天计划）

核心策略：先预热铺量 → 峰值冲刺 → 调休日补量 → 长尾维护。每天 21:00 前完成当日登记。

日期 阶段 目标投递量 重点动作 渠道侧重
10.04（首批） 预热 20–30 家 第一梯队 P0 打满，话术A/B 跑通 BOSS + 内推
10.05 预热 15–20 家 第二梯队 P1 启动，简历分两版 BOSS + 猎聘
10.06 预热 15–20 家 补齐 P1，开始第三梯队头部 BOSS
10.07 爬坡 25–30 家 复盘话术回复率，优化开场白 BOSS + 内推
10.08（峰值） 冲刺 50 家 三梯队全覆盖，当日集中爆发 BOSS 为主
10.09 维护 15–20 家 跟进 10.04–10.06 已读未回 私聊跟进
10.10（调休日） 补量 30 家 长尾中小公司 + 冲刺腾讯/字节精投 BOSS + 官网
10.11–10.13 维护 每日 15–25 家 沉默7天重投、约面转化跟进 全渠道
10.14 起 持续 每日 15–30 家 面试并行，存量维护 + 新机会 全渠道

节奏纪律：每天固定 2 个投递时段（早 9:30–10:30、晚 20:00–21:30），避免碎片化刷 BOSS 降低效率。

五、打招呼话术模板（BOSS 直聘开场白）

三版轮换使用，避免被系统判定重复。每版 80–120 字，务必把"40+ 银行渠道、报文比对 2 人天→0.5 人天、FastAPI 全栈自研"这三点塞进去。

版 A · 金融科技对口版（投第一梯队乙方用）

您好，4 年金融科技测试经验，主攻保险资金结算与银企直联，独立对接过 40+ 银行渠道的报文联调与对账。上家用 FastAPI+Vue3 自研了报文比对与自动部署工具，把报文比对从 2 人天压到 0.5 人天、部署从 3 分钟降到 10 秒。贵司资金/支付方向与我高度匹配，期待聊聊测试开发岗，方便发份 JD 吗？

版 B · 测开通用版（投第二、三梯队用）

您好，我是测开工程师，4 年金融背景 + 双能力：既能 Java 白盒定位根因，也能用 FastAPI/Vue3 全栈自研测试工具。曾把报文比对从 2 人天降到 0.5 人天、自动部署 3 分钟→10 秒，落地过持续提效。熟悉 40+ 银行渠道对接场景。看贵司在招测试开发，我的自动化与工具化经验可直接复用，方便沟通吗？

版 C · 猎头回复版（猎聘/猎头微信用）

X 老师好，我是尹胜，4 年金融科技测试开发。核心标签：保险资金结算+银企直联（40+ 银行渠道）、Java 白盒定位 + FastAPI/Vue3 全栈自研工具、自动化提效（报文比对 2 人天→0.5 人天）。目前看深圳 15–20k 的测开/自动化岗，10 月中旬起可连续面试。若有对口金融科技或测开机会，麻烦帮推，简历随后发您，谢谢！

六、跟进话术

1）已读不回 · 第 3 天追一句

您好，之前给您发过打招呼，我这边 4 年金融科技测试开发，做过保险资金结算和银企直联（40+ 银行渠道），自研工具把报文比对从 2 人天压到 0.5 人天。看贵司岗位还在招，方便的话想争取个沟通机会，打扰了～

2）面试后感谢语（24 小时内发）

X 老师/面试官您好，今天和您聊 [公司名] 的 [岗位] 很受启发，尤其关于 [提到的一个具体技术点或业务点] 的讨论让我对贵司质量体系有了更具体的认识。我补充一点：之前在银企直联报文自动化上的实践，应该能较快迁移到贵司的 [相关场景]。再次感谢时间，期待后续进展，祝工作顺利！

3）offer 谈判期跟进（沉默 3–5 天时）

X 老师好，非常感谢 [公司名] 的 offer，我对团队和业务都很认同。关于薪资我期望落在 15–20k 区间（结合 4 年金融测试开发 + 工具自研提效的产出），如果能在 [具体数字] 这一档达成共识，我可以尽快确认入职时间。另外想确认下 offer 发放的节奏，方便我同步安排，谢谢！

4）沉默 7 天重投话术（换渠道/换 JD）

您好，之前在 [原渠道] 投递过 [岗位]，一直没等到回复。我 4 年金融科技测试开发，保险资金结算+银企直联（40+ 银行渠道），自研 FastAPI 工具提效明显。看贵司还有 [新岗位名] 在招，重新打扰，方便的话想争取沟通，谢谢！

最后提醒：台账的价值在于"真实 + 持续"。数字不好看没关系，沉默 7 天批量重投比自我怀疑有用得多。13 天集中期结束后，本台账转为周更维护即可。
